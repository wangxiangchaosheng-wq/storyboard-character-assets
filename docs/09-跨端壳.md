# 09 · 跨端壳（桌面 Electron / 移动 Capacitor / 小程序 Taro）

> 产品承诺：**桌面 + 网页 + 小程序 + 安卓 + iOS**，桌面优先（Steam 形态）。
> 核心原则：`apps/web` 的 React 逻辑层是唯一"渲染真身"；各壳只做"容器 + 平台能力"，共享 `shared/contracts` 与 `engine-core`。

## 1. 目标矩阵

| 端 | 容器/工具 | 目标 | 架构思路 |
|---|---|---|---|
| 网页 | 浏览器 | 评审/试玩 | SPA 直出（`apps/web`）|
| 桌面 Windows/mac | **Electron**（electron-vite + electron-builder） | 黑客松演示 + Steam | 复用 web 构建产物包壳；可选 `Tauri` 备选（包小） |
| 安卓 / iOS | **Capacitor**（包同一 SPA → 原生壳） | 后端一键出包 | `capacitor add android/ios`，供商店发布 |
| 微信小程序 | **Taro 3**（React 语法） | 渠道触达 | UI 轻量重写（小程序无 DOM/WebView），**共享层不变** |

## 2. 共享层（不因端重写）

```
shared/
├─ contracts/     # 05 接口类型 + SSE 事件类型（唯一真源）
├─ engine-core/   # 02/03/04 无 UI 逻辑，直接被各端引用
└─ sdk/           # ws 统一能力：apiClient、streamClient、storage adapters
```
所有端壳 import `shared/*`；**禁止在壳内重写引擎/规则/缓存逻辑**——只允许「渲染映射」。

## 3. Electron 壳细则

- 主进程：加载打包后的 `dist-web`；`steamworks.js`（Steam 登录/成就）/ 本地模式下不开服务，引擎直跑于 `preload` 提供的 `gameBridge`（IPC 封装 engine-core 调用）。
- 渲染进程：与 web 完全一致（无 `node` 直接打开；只通过 preload 白名单 API）。
- 打包：electron-builder → NSIS（win）/ DMG（mac）；应用图标/名称占位与游戏内一致。
- 认证：MVP 无登录（本地游玩）；接 Steam 后走 `authentication.steam` 上报 `openid`。

## 4. Capacitor 壳（安卓/iOS）

- `capacitor init`；web 构建产物 `web` 目录作为 `www` 直接打包。
- Android：`capacitor add android` → 构建 apk/aab（Twa 亦可选针对商店需要）。
- iOS：需 Mac + Xcode（提交流程另文）；MVP 阶段以「构建通过 + 真机预览」为验收。
- 注意：WebView 卡顿留意 `window.webkit` 配置；SSE HTTP/2 + 心跳已在 05 做过。

## 5. Taro 小程序壳

- 技术：Taro 3（React），`@tarojs/plugin-platform-weapp` 等。
- 页面尽量映射 SPA 7 页；复用 `shared` 的 `apiClient` 与类型。
- **UI 无 DOM**：地图调整为静态图 + 点击热区（Canvas 替代），聊天用组件原生 ScrollView。
- 发布：微信后台配置合法接口域（我们 05 后端需要 HTTPS 域名 —— MVP 用 dev tunnel/tailscale 演示即可）。

## 6. 环境与构建脚本

- `pnpm build:web && pnpm build:desktop && pnpm build:mobile && pnpm build:mini`
- 各端独立 CI Job（GitHub Actions），`desktop` 同时产出 Steam `win` 安装包产出。

## 7. 验收清单

- [ ] **网页**：一局完整可玩（无壳）
- [ ] **桌面**：win10/11 打开 → 本地引擎模式玩一局；Steam 模拟登录（本地 dev 变量）通过
- [ ] **安卓**：APK 安装到终端模拟器 → 连接同一个后端 → 完整一局
- [ ] **iOS**：模拟器（mac 环境若有）构建成功、页面渲染
- [ ] **小程序**：开发者工具打开 → ingest/生成/决策接口可通（网络白名单配置过）
- [ ] 四个壳同时复用 `shared`（git 里 grep 确认无重复契约实现）
