# 主页策略地图库

主页虎符进入 `/strategy`。列表从 `/strategy/library.json` 读取，按 year 升序显示。目前 maps 为空，不把示意策略作为实际记录。

JSON 格式：`{ "version": 1, "maps": [] }`。每个 maps 条目包含：

- id：唯一地图快照 ID
- topicId、topicTitle：所属议题 ID 与名称
- title：策略标题
- year：数值公元年份
- place：地点名称字符串
- keywords：统帅及检索关键词数组（可选）
- mapUrl：战略地图 SVG 地址（可选，默认现有战略地图）
- data：StrategyData，字段见 app/lib/strategy.ts 和战略地图接入.md；包含军队、城池、行动、决策、变化记录、世界时间。

世界地图 Agent 完成后写入此清单和地图快照文件，或替换页面的数据读取地址。每条地图应对应独立快照，保持记录 ID 稳定。自定义地图需沿用当前 1725×863 画布和左右卷轴位置；交互数据坐标遵循现有战略地图接入约定。

检索支持议题、年份/年份范围、地点与策略关键词。“全部策略地图”忽略文本检索，显示所选议题下所有地图。点击条目加载其地图与交互数据，重新播放战略卷轴展开。返回地图先收卷再回主页。讨论页虎符保持原有原地叠加模式。
