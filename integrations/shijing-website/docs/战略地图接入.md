# 战略地图数据接入

虎符在当前对话页打开战略卷轴，不切换路由。打开2500ms、收起1100ms，尊重系统减少动态效果设置。

在 GET /api/agents/runs/:id 返回对象上添加 `strategy` 字段，形状见 `app/lib/strategy.ts` 的 StrategyData。前端每次同步议题时读取最新数据。未提供 strategy 时展示明确标注的交互示意，不代表玩家已下令。

- armies：id、name、faction、commander、troops、food、morale、position、location、status。
- cities：id、name、position、controller、governor、food、defense。
- actions：id、decisionId、armyId、from（城市ID）、target（城市ID）、route（坐标点数组）、progress（0–100）、time、status。
- decisions：id、title、command、time、status、objects（关联对象ID数组）。
- changes：decisionId、time、objects、before、after、reason。数值前后值与单位请组成可读文字。
- worldTime：startYear、elapsedDays。起始年代与已过天数分开显示，不猜测起始月份日期。

坐标使用提供的事件地图 SVG 的 1725×941 画布，左上角为0,0。军队与城市 position、路线 route 坐标在同一空间。汉中约810,438，长安约952,338。军队、城市、行动、决策 ID 应全局唯一。未提供的数据用 null 或省略，UI显示待接入；零值会正常显示为0。粮草的统一计量单位请由 Agent 约定，当前页面不自行换算。

决策 objects 与行动 decisionId 控制高亮联动；变化记录由 objects 和 decisionId 关联到详情卡。城市、军队、行动可鼠标点击或键盘 Enter/空格打开详情。确认并收卷及 Escape 都播放收起动画。

此版本只展示数据，不向世界 Agent 下达命令。Agent 接入时由服务端校验数据与权限后返回，不把浏览器点击视为已执行决策。
