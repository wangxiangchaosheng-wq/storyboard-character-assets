# 史境网页与素材

这是独立运行的史境网页，包含 50 张历史事件图、人物素材库、议题事件卷轴及生成服务。

## 启动

安装 Node.js 22.13 或更新版本，进入本目录后执行：

```sh
npm ci
npm run dev:agents
```

macOS 也可双击本目录的「启动史境.command」。默认网页地址 http://localhost:3002。

首次启动会从 `.env.example` 创建 `.env`。在线生成需自行填写 API 配置；没有上传个人密钥和运行记录。离线素材可直接使用。

## 与主仓库对接

本目录保留独立 package-lock.json，使用 npm 安装。推演引擎需通过 SIM_ENGINE_URL 等配置连接，尚未自动接入主仓库服务。已有议题记录及自动生成任务数据库不随源码上传。
