史境 Agent · 离线素材修复版

1. 解压后双击“启动史境.command”。第一次会安装依赖。
2. 打开 http://localhost:3002 ，从主页填写议题并进入讨论。
3. 不需要填写 API Key；当前使用本地预设选角，优先匹配题目中明确提及的人物，再补充阵营预设人物。北伐默认诸葛亮、魏延、杨仪、姜维、费祎。
4. 30 张人物 PNG 在“人物素材库”。男、女大学生独立匹配。
5. 本版不调用 API。缺少的人物图和故事板不会自动生成；角色对话、行动裁判需要接入队友引擎。
6. 已接入过渡 SVG 和实时人物任务进度条。已有素材快速进入，缺图或失败可先进入。绘制进度按任务阶段更新，不表示生图服务的精确百分比。
7. 已移除顶部工具栏；议题画面按网页宽度等比例显示，上下空余为黑色。点击烛火返回主页。

若旧版本仍在运行，请先在旧终端按 Control+C，再启动此版本，避免端口被占用。
本包不含你的密钥与旧议题记录。
