# 一张图讲清当前故事

## 场景选择

先提炼“什么人在什么环境里做什么，体现了当前故事的什么变化”，再组织一张完整场景。可以有远近层次，但不能拆成连续镜头，不要画聊天记录。

以下是构图提示，不作为历史证据：
- 草船借箭：按演义故事语境表现雾中船只、草束受箭和江面氛围。用户若讨论其他版本，以该版本为准。
- 子午谷奇谋：以险峻山谷、隐蔽行军或战略路线意象表现奇袭设想。方案讨论不自动变成成功战报。
- 北伐失败：以当前语境中的撤军、疲惫队伍、收拢的军旗和受挫氛围表现失败阶段。没有依据时不添加具体伤亡、战役名称或某人阵亡。

每次仅选择当前主题。不要把雾江、山谷行军和败退三种故事拼成多场景合集。

## 角色和环境

人物由场景需要决定，可单人、多人或以环境为主。通过具体动作、身体方向、视线和表情建立叙事，不全员站桩。时代化服饰、建筑与道具保持统一；没有可靠身份肖像时按时代视觉演绎，不声称真实还原。

无需先画人物立绘。没有参考图时直接生成完整背景与人物。用户提供参考图时明确其用途；风格参考不等于要复制其中的角色、道具或旧故事。

## 左侧总结文字

默认在画面左侧构图相对疏朗的区域放一段总结文字，参考用户示例的竖排题记布局。正文自上而下，多列时从右向左阅读；通常一至两列，长度以清楚概括事件且适合画幅为准，建议约 12–30 个汉字。留足边距，以清晰的中文字体和足够对比度保证可读，不压住人物面容、手势或关键行动；文字直接融入原有场景，不另做侧栏面板或分格，不加白色蒙版、浅色雾化衬底或文字底板。“预留空间”指构图疏朗，不是把背景涂白。

**字色规则：夜间场景使用白字，日间场景使用黑字。** 依据故事时间判断，夜间室内有灯也仍用白字；日间阴天仍用黑字。黎明、黄昏或时间未明时，按画面整体明暗选择白字（暗）或黑字（亮）。生成提示词须明确指定字色；通过选择合适的文字位置保证可读，不恢复白色蒙版。用户明确指定其他字色时遵从本次要求。

文字概括当前故事的处境、抉择或关键转折，不只是标题，不逐轮摘抄对白，不虚构尚未发生的结局。用户提供确切文案时优先原文；否则在生成前自行提炼，并在提示词中逐字列出最终文案和竖排要求。不要写“无文字 / no text”之类与总结要求冲突的总禁令；只禁止额外文字。切换话题时同步重写总结，不复用参考图的“子午奇谋”等旧题文字。参考图在本项用于文字布局，不自动固定后续所有画风、地点标签或印章。

例如本次撤军救援对话可概括为：“粮尽撤军，限时救援；一纸军令，二人共担。”这一文案是示例，不是跨话题固定文案。检查实际图片中文字是否完整、准确、可读；发现缺字、错字或乱码时定向修正。

## 内部提示词结构

主题：当前规范主题与必要语境。
事实性质：史实场景 / 小说情节 / 假设推演 / 概念演绎。
主体与行动：最能体现故事的关键行为。
场景：地点、时间、气候、远近关系。
构图：一张完整连续画面，视觉焦点清晰，左侧预留总结文字空间。
文字：逐字给出当前故事的总结短文，指定左侧中文竖排、清晰字形、阅读顺序，以及夜间白字或日间黑字，文字直接叠在场景上、无蒙版衬底；用户明确要求无字时省略。
风格：用户或上游传入的风格，否则适合题材的统一插画。
画幅：默认竖版宽:高 = 452:801；只有用户明确要求其他比例时才覆盖。按竖幅安排人物和环境层次，不由题材或容器自行决定画幅。
禁止项：分格、拼贴、连续镜头、镜号、漫画气泡、脚本、长文字、UI、水印，以及与本题无关的旧话题元素。

提示词是执行工具的内部材料，默认不作为用户交付物。请求精确像素时核实真实文件大小，不能只凭提示词声称符合。
