# 当前话题 → 单张故事场景图

本技能里的“故事板”指**一张表现当前故事或事件的完整场景图片**。默认每次生成 1 张，画幅为竖版 **宽:高 = 452:801**，单一连续画面，左侧配一段概括当前故事的竖排短文，可有多人、建筑、地形和事件动作；不拆格、不编号、不交付脚本。对话提供的是题材与语境，不是要画出来的聊天界面。

## 输入与职责

可接受一个主题、一段最近对话，或上游 agent 的结构化调用。无需用户预先提供故事板、人物立绘、背景或参考图片；无资产时直接从文本生成。已有参考图只是可选的风格、构图或身份辅助。

上游 agent 负责接收新消息、识别是否需要调用，以及显示最新图片；本技能负责从当前输入定位主题并完成实际生图。不要自行创建后台任务、定时器或监听器。接入、输入字段、去重和结果状态见 [references/output-contract.md](references/output-contract.md)。

## 1. 定位此刻真正讨论的故事

读取 [references/context-routing.md](references/context-routing.md)。优先级：
1. 本次调用明确指定的当前主题；
2. 最新实质消息中的主题转换及其指代；
3. 最近可见对话延续的事件和事件阶段。

上游显式传入 active_topic 时把它作为本次创作目标；如果附带了更新的消息且明确推翻该主题，按最新纠正更新。没有 active_topic 时默认回看最近 6 轮可见对话，按需追溯相关上下文。不是收集六轮中的所有主题，也不是每轮生成一张图。最近一句明确换题即可覆盖此前多轮的旧主题。

区分主题、事件阶段、谈论角度、操作要求和示例。草船借箭、子午谷奇谋、北伐失败可以依次成为独立当前主题；不能把它们拼成一张“三国故事合集”。“像草船借箭一样”“不要画草船借箭”或说明技能行为时列举故事名，不自动切题。

内部只需确定：当前主题、世界观/事实性质、时间或事件阶段、最有辨识度的场景、当前有效视觉约束和置信度。不把分析表、选角表或推理过程交给用户。一个合理主题已经清楚时直接生成，不反复要求确认。

## 2. 把主题变成一幅能看懂的故事画面

选择最能体现主题的一个场景或一个关键时刻，用人物行为、环境与氛围让人看出故事。可以用前景人物、中景行动和远景目标组织连续画面；不要通过六格、多镜头时间线、漫画气泡或长篇说明来叙事。

按当前话题的重点选画面，而不是只按题目抓关键词。例如同为北伐，出征与失败撤军是不同事件阶段，应该生成不同场景。当前主题是“北伐失败”时，视觉焦点应转到失败后的撤军、疲惫与受挫氛围，不继续画旧主题的进攻路线。

简化复用原人物资产方法：按事件需要选人物，让人物有具体主动作、目光对象与姿态，统一全图美术风格。不固定人物数量、不限制只能半身或只能一件道具、不先生成角色包，不要求现有资产。

事实、小说与假设不能混同。“草船借箭”可以按用户正在讨论的演义故事可视化，不将其声称为已证实的史实；“子午谷奇谋”若在讨论方案，就画方案设想而不擅自画成已经攻克长安。真实事件的关键身份、阶段或器物拿不准时，按环境规则使用可靠来源核实；无依据细节可省略。不要把一般失败场景强行指定为某次真实战役、某人的死亡或特定年份。

构图与提示词方法见 [references/visual-production.md](references/visual-production.md)。

## 3. 直接生成实际图片

使用当前可用的图像生成工具。环境提供 imagegen 技能时先读取并遵守它；根据工具真实参数调用，不臆造模型名、尺寸、透明背景或批量字段。没有参考图时从零生成，不要求上传资产，不伪造参考路径。

故事板默认使用竖版 **宽:高 = 452:801**，跨话题沿用；不得根据题材或展示容器自行改成横版、方图或近似的 9:16。只有用户明确要求其他比例时才覆盖此默认值，上游参数应体现用户要求。452:801 是宽高比，不是固定分辨率；可使用 452×801、904×1602 等同比例尺寸。生成提示词必须明确写出此比例，并按竖幅组织前、中、远景。画风优先遵守用户或上游的明确要求，否则选择统一的叙事插画风格。图内默认必须有左侧总结短文：用一句精炼文字概括当前事件的处境、关键抉择或转折，不能只有故事名，也不照搬整段对白。采用左侧预留文字空间、中文竖排，文字直接融入场景，不添加白色蒙版、浅色底板或人为提亮的文字衬底。**夜间场景用白字，日间场景用黑字**，按故事中的昼夜判断，室内灯光不改变此规则；具体写法和排版见 [references/visual-production.md](references/visual-production.md)。用户明确要求无字时才省略。默认不加额外标题、对白气泡、长段说明、边框、网格、水印或 UI。

主题改变时从新主题重新构图；可沿用画风，不沿用已经过时的船只、山谷、角色、道具和行动状态。只有用户要求编辑同一张图时才按编辑模式处理。

缺少图像生成能力时说明“本次图片未生成”；面向 agent 返回 blocked 和原因。不以脚本、提示词、空白框或占位图充当故事板，不擅自启用付费 API。

## 4. 验收、保存与返回

查看实际图片：是否一眼符合当前主题、是否一张连续场景、是否残留旧话题元素、人物和行动是否清楚、风格与比例是否正确，以及左侧总结是否存在、贴合当前故事、字形准确且清晰可读。检查夜间白字、日间黑字及无文字蒙版的要求。将实际文字逐字对照生成前确定的文案，不能以乱码、缺字或遮挡主体的文字通过验收。核实落盘文件和实测尺寸；默认比例用 width × 801 = height × 452 验证，不能只凭提示词声称符合。若需修正，使用当前工具允许的方式，避免强行拉伸。工具无法输出精确比例时如实说明实际尺寸和偏差，不把近似比例标为通过。针对明确缺陷最多再做 2 次定向修正，仍失败就说明失败，不无限重试。

保存到当前工作区 output/storyboards/<topic-slug>/<generation-id>.png 或实际输出格式。generation-id 使用本次唯一标识；新图不覆盖旧图。每个已处理主题图可留存，但本次面向用户只展示当前图，不能把历史图重新当作本次成果。

普通用户调用默认只展示 1 张最终图片，可带极短主题说明；不附脚本、镜头表、素材清单或过程文档。面向 agent 时按输出契约返回图像路径和状态，供上游替换展示；这些元数据不是面向用户的故事板内容。
