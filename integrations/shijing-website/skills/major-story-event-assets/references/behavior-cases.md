# 触发与验收案例

以下是行为要求，用于检查实现；不表示已运行真实生图测试。历史题材示例也不是历史事实证据。

| 输入情境 | 预期 |
|---|---|
| “我决定增兵救街亭”，后续尚未展开 | not_triggered：下令不等于已经救下街亭 |
| 角色说“此计必胜”，用户仍在质疑粮道 | not_triggered：角色信心不是结果成立 |
| 对话明确推进到援军抵达、要地守住、整场战局逆转 | 生成守住要地的结局图；若改写历史，时间题记标为架空推演 |
| 仅讨论街亭失守会有什么后果 | 不把讨论对象当成当前分支已经发生的事件 |
| 用户明确要求“画一张街亭守住后的假设结局” | 可生成，图内时间题记注明假设推演，不改变主线状态 |
| 北伐方略重写，只确定粮限与撤军条件 | not_triggered：不能自动画成攻下长安或北伐胜利 |
| 对话明确确立关键人物获救，改变了后续政权继承 | 达到重大结果门槛，画获救后的关键时刻，非普通立绘 |
| 只送出一封例行情报，没有确定重大影响 | not_triggered，不因出现历史名人就触发 |
| 用户纠正“刚才只是设想，还没有出兵” | 撤销本次生成触发，不复用为主线已发生结果 |
| 同一分支重复说明同一已出图结果 | 旧图有效且要求未变则 unchanged |
| 同一战役另一分支得到相反结局 | 新图单独保存，不覆盖旧分支成功资产 |
| 架空结果只知道年份 | 年份加“架空推演”；不补月日 |
| 完全没有故事时间 | 标“故事时间未明”，不能用系统日期 |
| 夜间军帐，灯火很亮 | 左侧总结和时间均为白字，无白色蒙版 |
| 日间山谷，背景有天然云雾 | 黑字，保留自然云雾，不加文字衬底 |
| 普通故事图曾使用 452:801 | 重大结果图默认仍用横向 1537:636 |
| 输出宽高仅接近 1537:636 | partial，记录实测尺寸，不提交验收成功状态 |
| 图片中文字缺字或时间错误 | 定向修正；仍错则 partial，不以文字说明代替图内修正 |
| 用户只要求完成本技能并附示例图 | 创建技能，不顺便生出示例事件图 |

人工审阅重点：是否有清楚的“决策 → 结果”依据，是否把未定假设写成胜败，左侧文字是否包含结果与时间，画面是否表现重大后果而非泛泛议事。
