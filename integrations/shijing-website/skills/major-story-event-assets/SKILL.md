# 重大故事结果 → 横向结局资产

每次处理一个当前有效的重大结果，交付 **一张宽:高 = 1537:636 的横向完整场景图**。左侧配总结短文和事件时间。画面表现决策导致的结局或转折，不把多轮对话拆成分镜，也不交付人物立绘包。

## 1. 判断是否形成重大结果

读取用户决策、相关后续对话和最新纠正，确认“作了什么决定 → 对话推演发生了什么 → 什么重大结果已经成立”。不要求固定轮数；以当前分支为准，不把所有历史分支合并。

当结果同时满足以下两点时自动进入生成：

- **已经成立**：用户或双方共同推进的叙事明确确认事件发生、分支结果落定。单纯下令、提出战术、预测可能性、角色劝说或尚有争议的推测都不算。上游传入的结果与可见对话冲突时，以最新明确纠正为准。
- **具有重大影响**：改变关键战役胜负、战略格局、政权兴衰、关键人物命运，或使历史重大事件发生、避免、逆转。普通行军、小范围动作或例行对话不自动升级为重大事件。

用户明确要求把某个假设结局画出来时，可以生成，但必须标为假设推演，不把该假设提交为主线已发生的结果。世界观不限于三国；按当前故事选取人物、时代与环境。

尚未落定则简短说明还没有形成重大结局，不代替用户作决定、继续编演战争或凭历史常识补上结局。只有缺失信息会改变画面核心时才询问。判定示例见 [references/behavior-cases.md](references/behavior-cases.md)。

普通场景由 conversation-storyboard 处理；本技能专门处理重大结果，不继承普通场景的 452:801 竖幅，也不在一次事件调用中额外生成普通场景图。

## 2. 确定事件性质与时间

内部确定：事件名、关键决策、结果、因果依据、当前分支、涉及人物、地点、事件时间，以及性质（史实 / 演义或小说 / 架空改史 / 假设推演）。不要给用户输出长篇分析表。

时间指故事中的事件时间，绝不是当前系统日期：

- 用户或对话已明确时间，按其精度呈现；只有年份便不编造月日。
- 若要把结果作为真实历史事件呈现，关键年份和事实不确定时，用可用可靠来源核实。没有核实依据时，不声称历史复原。
- 架空改史沿用已建立的故事时间，并在时间题记中加“架空推演”；明确假设图加“假设推演”。不能给改史结果贴上纯史实时间标签。
- 年代未知但有相对时间时可写“撤军次日”等；二者都没有时写“故事时间未明”，不随意补一个朝代年号或公元年份。

左侧总结写结果本身和关键代价或转折，通常 12–28 个汉字，避免只有故事标题或空泛感慨。时间单列，不能用生成日期顶替。确切文案由用户提供时优先使用；没有则直接提炼，无需先等用户审稿。

## 3. 生成横向长图

先读取当前环境的 imagegen 技能并遵守其工具规则，使用真实可用的图像生成能力。需求中的 Image 2 是模型偏好：当前工具支持并公开该选择时使用；没有模型选择参数则不臆造参数、不宣称已调用特定模型。不要为此擅自切换到另计费的 API 或 CLI。没有可用生图工具时明确返回未生成。

画面要求：

- **横向 1537:636**，推荐目标尺寸 1537×636 像素；只指定比例时可用同比例更高分辨率。用户明确指定其他尺寸或比例时遵从本次要求。不得自行换为 16:9 或竖图。
- 一张连续场景，以最能说明结果的时刻为主体。人物、行动、近景后果与远景环境有因果联系；不使用拼贴、分格、地图加小窗或多时刻合成来凑“长图”。
- 左侧预留疏朗空间，放中文竖排总结；多列从右向左读，每列从上向下读。时间用较小字号列于总结左侧，竖排排版，边距充足，不遮挡人物面容和关键行动。
- **夜间白字，日间黑字**，时间与总结同色。夜间室内有灯仍用白字，日间阴天仍用黑字；晨昏或时间未明时按画面明暗选白或黑。文字直接融入场景，不加白色蒙版、雾化衬底或文字面板。天然天空、墙面等疏朗背景可以承载文字。
- 优先沿用用户已确认的画风、人物参考和当前故事资产。缺少资产可直接从文本生成。默认采用精细线描、克制水墨设色与统一材质的历史叙事插画；虚构世界按设定调整。参考旧图可延续画风，不复制旧事件、题记、伤亡或角色。
- “画面去噪”指减少无关角色、重复道具、杂乱旗帜、过密细节和生成伪影，保留清晰焦点及有用叙事信息，不把画面处理成模糊或抹去合理材质。

生成前在提示词中写明：事件性质、已经成立的结果、关键时刻、人物动作、场景层次、画风、横向比例、昼夜、左侧总结原文、时间原文、字色和无蒙版要求。禁止对白气泡、UI、网格、水印和额外文字，不使用与必要题记冲突的“no text”总禁令。

## 4. 验收与保存

查看实际图片：结果是否正确，是否擅自增加胜败或死亡，画面是否连续且清楚，人物与风格是否一致，是否仍带旧事件元素。逐字检查总结、时间及推演标识，检查字色和无蒙版要求。

实测文件尺寸，默认比例验证 **width × 636 = height × 1537**。仅在提示词中要求尺寸不等于尺寸已通过。针对明确缺陷最多做两次定向修正，使用工具允许的编辑方式，不强行拉伸。仍有比例偏差或错字时，交代实际情况，可保留预览，但不能标记为验收成功或覆盖既有成功资产。

保存到当前工作区 `output/major-story-events/<event-slug>/<generation-id>.<实际格式>`，唯一文件名，不覆盖旧图。面向用户只展示本次图片，附必要的极短说明；失败不以提示词、脚本或空白框代替图片。

## 5. 上游接入

自动识别发生在调用本技能的上游 agent 处理新对话时；本技能不自行部署监听器、定时任务或后台循环。输入输出、分支去重和状态提交见 [references/agent-contract.md](references/agent-contract.md)。编写或修改技能本身时不生成截图里的示例图。
