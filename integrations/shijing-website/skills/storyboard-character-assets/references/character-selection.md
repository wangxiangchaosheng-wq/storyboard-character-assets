# 人物选择方法

仅在主题需要研究或阵容不明确时读取本文件。目标不是列出所有相关人物，而是找出真正改变事件走向的角色。**未指定数量时固定选 5 个最不可替代角色，并最终交付 5 张 PNG**；只有用户明确要求其他数量时才改变。

## 1. 先画事件链，再选人物

把主题拆成 3–7 个真正改变局面的节点，例如：提出目标、作出决定、执行、反制、转折、见证/传播、收束。为每个节点找出实际承担作用的人或角色类型，再合并重复者。

优先覆盖以下功能中与主题确实有关的部分：

- 决策者：决定目标、资源或规则。
- 推动者：让事件从计划进入行动。
- 反对者/制衡者：制造主要阻力或替代路径。
- 关键执行者：通过能力、行动或失误改变结果。
- 桥梁/见证者：连接阵营、记录事件或代表受影响群体。

这些是检查视角，不是固定配额。一个人可以承担多个功能；无关功能不必补齐。

## 2. 建立候选表

在内部为候选人记录以下字段：

| 字段 | 用途 |
|---|---|
| 名称与别名 | 避免同名或译名混淆 |
| 身份类型 | 历史人物、当代人物、虚构角色、合成角色或角色原型 |
| 阵营/关系 | 解释人物之间的结构 |
| 事件节点与功能 | 说明为什么这个人能推动主题 |
| 不可替代性 | 删除此人是否会让事件链缺一环 |
| 事实状态 | 已确认、存在争议、仅传说/演义、用户设定或视觉演绎 |
| 视觉锚点 | 时代服饰、职业装备、轮廓、配色、可信道具 |
| Action Signature | 具体事件瞬间、能力来源、主动动词、手部/道具交互、重心、视线、剪影 |
| 禁止通用姿态 | 此角色最容易滑回的模板站姿，例如“正面站立拿道具” |
| 风险/歧义 | 身份不确定、形象无史料、易与他人混淆等 |

最终只向用户展示有助于理解和确认的字段，不必倾倒整张内部表。

## 3. 选择规则

1. 用户点名的人物默认保留，除非与主题明显冲突；发现冲突时指出并请求确认。
2. **未指定数量时固定选择 5 个最不可替代角色。** 先对候选人做反事实排序，取前 5 名，不因“因果链还可以继续扩展”而自动增加第 6 张资产。
3. 只有用户明确要求超过 5 张时，才为第 6 个及以后角色使用扩展角色门槛：删除该角色会使关键因果链断裂、重大方案分歧消失、关键反制缺席，或使对最终结论的判断发生实质偏差。仅仅因为知名、视觉好看、阵营更完整、能增加讨论度，不足以扩展。
4. 两个人若在事件功能、立场和视觉表达上高度重复，只保留更关键或证据更充分者。
5. 不把“知名”当成“关键”。人物必须能对应某个事件节点或叙事功能。
6. 不为了形式上的平衡硬加阵营；也不要只呈现单一权力视角而遗漏对结果有实质影响的一方。
7. 用户的故事目标高于百科全书式完整性。教育型内容重事实链；游戏/论坛模拟还要考虑立场差异与互动潜力。
8. **人物不能只靠“知名道具”区分。** 选角同时要检查其能否产生不同的行动语言；若两个人在当前主题里只能生成同一种站姿/动作，应重新审视是否真的都需要，或为他们分配更具体的事件节点。
9. **不要让题材把角色绑到同一种道具上。** 战争/北伐不等于全员地图，学者不等于全员书卷，现代人不等于全员电脑。选角阶段就要检查：这 5 人能否通过不同的任务动作和剪影成立，而不是靠重复道具换皮。


## 4. 默认固定五人规则与显式扩展门槛

未指定数量时按以下顺序选角：

1. 列出所有真实候选角色/角色类型。
2. 对每个候选人进行“删除测试”：如果把此人从事件链中删掉，哪些决定、资源、冲突、执行或反制会消失？
3. 按不可替代性从高到低排序，固定选择前 **5** 名并生成 5 张最终 PNG。
4. 不自动加入第 6 名；只有用户明确要求更多人物时，才对第 6 名及以后应用扩展门槛。

可用内部 10 分制辅助判断：

- 因果杠杆 0–3：是否能直接改变资源、决策、执行或结果？
- 决策/行动中心性 0–2：是否处在关键事件节点？
- 反事实不可替代性 0–2：删掉后是否出现明显因果缺口？
- 独特约束/立场 0–2：是否提供其他五人无法替代的关键反制、能力或限制？
- 事实/设定置信度 0–1：是否有可靠依据？

第 6 个及以后角色通常应达到 **8/10**，并且必须能写出一句：

> 如果删除 <角色>，对主题结论的判断会因为 <具体缺失的因果环节> 而发生实质偏差。

写不出来，就不要加。

### 群体角色

“1 万大学生”“百姓”“军队”“科研团队”等群体默认只占 **1 个角色位**，生成一个代表人物资产。只有当群体内部子角色（如工程、医学、物流）分别满足扩展门槛时，才拆成多个角色。拆分后每个仍是一张独立单人物资产。

## 5. 事实与来源

- 历史主题：优先档案、权威史料、博物馆/大学或可靠研究资料；把史实、后世叙事和影视印象分开。
- 当代主题：核对截至当前日期的身份与事件进展，并在方案中写清时间截点。
- 虚构主题：优先用户提供的材料和正式设定；二创推断应标记为推断。
- 没有可靠肖像时，只能描述为时代化或设定化的视觉演绎，不能声称“真实长相”。
- 来源只支撑它实际证明的内容。不要用一个页面为整段未经核实的描述背书。

## 6. 对用户的角色方案

每个角色使用一条紧凑记录：

```text
人物：<名称>
事件功能：<他/她改变了什么>
入选理由：<为什么不可替代>
视觉锚点：<服饰/道具/轮廓>
Action Signature：<事件瞬间 → 能力来源 → 主动动词 → 手/道具 → 重心 → 视线 → 剪影>
禁止通用姿态：<最不应该生成的模板动作>
依据：<已确认/存在争议/用户设定/视觉演绎；必要时附来源>
```

只有当两个合理阵容会导向互不兼容的人物身份描绘，而且没有保守默认值时，才停下来让用户选择；否则采用更小、更有证据的方案直接进入生成。
