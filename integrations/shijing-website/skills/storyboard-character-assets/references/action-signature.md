# 人物动作签名：从“角色名”到“这个人此刻会怎么动”

本文件用于解决角色立绘常见的“所有人都站桩、拿道具、看侧面”问题。生成前必须先遵守 [atomicity-contract.md](atomicity-contract.md)：**一个角色只有一个主动作，其他人物不得进入画面。**人物动作必须来自**人物身份 × 性格/决策方式 × 当前事件功能 × 此刻任务**，而不是来自通用人物立绘模板。

## 1. 先建立 Action Signature

生成每个人物提示词前，先在内部写出以下字段：

| 字段 | 要回答的问题 |
|---|---|
| Event moment | 现在是事件链的哪个具体瞬间？不是笼统“在北伐中”，而是“正在权衡子午谷突袭与稳健补给” |
| Narrative function | 此人此刻在决策、说服、执行、反制、观察、记录、发明还是质疑？ |
| Competence source | 他/她靠什么能力解决问题：军略、政治、工程、医学、现代知识、体力、组织、情报等？ |
| Decision temperament | 稳健/冒险、克制/激烈、审慎/果断等；只使用有依据或用户设定支持的特征 |
| Physical verb | 用一个可画出的主动动词定义动作：标注、推演、测量、指向、拆解、递交、巡视、质询、冲锋…… |
| Object interaction | 手真正碰什么、怎么碰；历史人物默认应与已经核验的核心道具发生可读关系 |
| Prop Card | 按 [historical-props.md](historical-props.md) 为每件可见道具写名称、功能、证据等级、直接来源、形制、交互、允许声称范围与禁加项 |
| Upper-body posture | 半身框内的上身朝向、肩线、手肘开合和头部角度如何变化；默认不得依赖蹲、跪、跨步或完整下肢表达动作 |
| Gaze target | 目光具体看向谁/什么：文书、军标、对手、伤员、器械、远处目标等；不要默认写‘地图线路’ |
| Expression | 情绪强度与任务一致，不使用统一“沉着严肃脸” |
| Silhouette cue | 从黑色剪影也能区分此人与同组其他角色的姿态特征 |
| Forbidden generic pose | 明确禁止最容易滑回的模板动作，例如“正面站立、双臂自然垂下、拿羽扇摆拍” |

`Physical verb` 是核心字段。若无法写出一个与主题强相关的主动动词，说明动作设计还没有完成。

## 2. 动作必须与人物能力发生关系

错误逻辑：

> 诸葛亮 = 羽扇 + 长袍 + 侧身站立

正确逻辑：

> 诸葛亮在“北伐决断”节点的能力是战略规划与组织调度，但人物资产不必把抽象能力做成器械。羽扇若采用，必须记录早期后世文献来源、器物时代适配与证据年代差，标为 `LATER-TEXT-ATTESTED`；若不满足就不用。其他物件同样逐件核验。

错误逻辑：

> 大学生 = 年轻人 + 双肩包 + 站立

正确逻辑：

> “现代大学生穿越三国并试图改变蜀国命运”的叙事价值来自跨时代知识差，但不得把这种抽象差异做成“古代数据板”等伪器物。优先用少量、来源清楚的普通书写材料和解释手势；若道具并非一眼可辨且没有可靠形制，就不用道具。除非当前任务明确是地理路线分析，否则不要给大学生地图。

## 3. 动作生成层级

按以下顺序推导，不要跳步：

```text
主题冲突
→ 事件中的具体决策/行动节点
→ 角色在该节点的功能
→ 角色真正依赖的能力
→ 一个强主动动词
→ 提出 2–3 个道具候选
→ 完成 Prop Card，选择 1 件有史据的核心道具
→ 手部与道具交互
→ 上身朝向、肩线与视线
→ 表情强度
→ 可区分的整体剪影
```

如果两个人最后得到相似动作，回到“角色功能/能力”层重新分化，而不是只改左右朝向。需要人与人互动的动作，也只画当前目标角色；通过视线、手势和身体朝向暗示对方存在，不把对方画进资产。

## 3.1 半身动作转换规则

默认资产是腰部以上半身像。先设计“半身能读懂的动作”，不要先想全身动作再裁切：

- 把前进、逼近、后退转换成上身前压/后收、肩线旋转和手臂伸缩。
- 把跪坐、伏案、半蹲转换成略微俯身、低头校核、双手在胸腹前操作小型道具。
- 把冲锋、跨步转换成武器/令牌形成的斜向线、紧张的肩臂与明确画外视线；不展示腿脚。
- 把端坐或礼仪动作转换成端正肩线、收束手势与身份器物；不画座椅、地面或膝部。
- 必要道具必须缩小到胸腹前可操作的尺寸；若动作只能靠完整桌案、地面或双腿成立，应换动作。

半身像不等于静止证件照。角色差异仍须通过双手、手肘、肩线、头部角度、视线和道具交互建立。

## 3.2 道具叙事/史实门槛与组内去同质化

Action Signature 与 Prop Card 联合设计，并做一次“防滥用、防删空”检查：

- **身份不是道具理由。** 军师 ≠ 地图，武将 ≠ 长枪，大学生 ≠ 笔记本电脑，医者 ≠ 永远拿药箱。
- 问：**这个道具是否显著增强动作可读性或角色辨识度？** 若是并且有史据，可以保留；不再因为手势勉强能成立就优先删除。
- 问：**角色是否正在使用或佩用这个道具？** 行动道具要被直接操作；身份道具可以佩用，但不能悬空陈列或变成环境装饰。
- 问：**同组别人是否也在用同一核心道具？** 若是，比较动作机制；如果只是“换个人继续拿/指同一个东西”，必须重设计。
- 真实历史题材再问：**这个道具类型在当时存在吗？图中形制有依据吗？** “算筹存在”“简牍存在”不能推出“手持算筹简牍调度板存在”。不得把多个真实名词拼成没有证据的新器械。
- 无法查证或名称只能临时自造时，更换下一个候选。没有找到 1 件合格人物道具前不得生成。不要让“现代思维”变成古代版屏幕、面板、流程板、棋盘或控制台。
- 后世常见识别物不享有豁免：必须同时具备史料/器物依据并进入证据分级；只有影视、绘画传统而无史证时删除。
- 每个角色必须恰好有 1 件人物道具；0 件或 2 件以上都说明研究或动作设计未完成。

### 地图专项门槛

地图只在动作明确涉及“读取、标注、推演、指认具体地理路线”，且没有地图就无法读懂该动作时使用。三国、北伐、军师、将领等关键词本身**不能触发地图**。

禁止把地图扩张成：疆域底图、路线箭头、地名标签、战略信息图或主题说明板。角色资产中的地图若必须出现，应保持局部、从属、少文字甚至无文字。

## 4. 三国穿越主题示例

主题：**“一个大学生穿越到诸葛亮北伐时期，怎样才能尽可能改变蜀汉的结局？”**

### 诸葛亮

- Event moment：北伐前作出是否改变既定部署节奏的决断。
- Narrative function：核心决策者 / 战略整合者。
- Competence source：军政统筹、后勤组织、风险权衡。
- Physical verb：**定令**。
- Object interaction：一手在胸前稳持白羽扇，另一手向画外做克制、明确的发令手势；不添加筹板、棋盘、算筹、地图或现代装置。
- Prop Card：白羽扇 = `LATER-TEXT-ATTESTED`；记录《语林》“诸葛亮持白羽扇，指麾三军”的早期后世文献传统及其与人物所处时代的年代差；只画素白羽片与朴素木/竹柄，不添加太极、八卦、宝石或机关；不得写成《三国志》已确证的实物。
- Upper-body posture：腰上半身微向画外命令对象转动，肩线稳定，抬起的手臂形成清楚但不过度戏剧化的指令方向。
- Gaze target：画外接受命令的将领；对方不入画。
- Expression：克制、略有疲惫但高度专注。
- Silhouette cue：稳定长袍轮廓 + 胸前羽扇 + 一侧克制发令手势。
- Avoid：筹板、棋盘、算筹面板、古代数据板、默认地图、仙术动作、夸张武将姿态、影视演员脸。

### 穿越大学生

- Event moment：把现代物流损耗概念转成蜀汉能执行的粮运规则。
- Narrative function：跨时代知识桥梁 / 方案提出者。
- Competence source：现代基础教育、信息整理、工程与数据思维（不要无依据设定其为全能专家）。
- Physical verb：**换算** / **转译**。
- Object interaction：一手持一片经形制核验的普通木牍作为古代可执行记录载体，另一手在胸腹前做分段、对照式解释手势；不得使用拼装算筹板、棋盘式面板或地图。
- Prop Card：普通木牍 = `PERIOD-ATTESTED`；以汉代简牍和文书用具的考古/博物馆资料支持载体类型，只声称“采用当时存在的书写载体进行视觉化演绎”，不声称是某一历史人物遗物，不添加现代图表、网格、按钮或可读数据。
- Upper-body posture：腰上半身略向记事板前倾，肩肘紧凑、动作快速，表现出一点不熟悉古代礼制的局促；不蹲、不跪、不画腿脚。
- Gaze target：自己的计算结果，偶尔抬眼确认听者是否理解；听者不画进资产。
- Expression：紧张、兴奋、急于证明方案可行，而不是成熟军师脸。
- Silhouette cue：更紧凑、更年轻、更动态；双手形成清楚的分段解释动作。
- Avoid：拿地图指远方、古装军师化、英雄抱胸、无目的站立、过度科幻装备。

### 魏延（如入选）

- Event moment：强硬推动一套更激进的快速突袭方案。
- Narrative function：进攻方案推动者 / 高风险执行者。
- Competence source：前线作战经验与快速机动。
- Physical verb：**逼请**。
- Object interaction：一手按住经考古形制核验的东汉式环首刀刀柄/刀鞘，另一手向画外决策者做强硬请战手势；兵器只作 `PERIOD-ATTESTED` 时代类型演绎，不声称是魏延实物。
- Prop Card：环首刀 = `PERIOD-ATTESTED`；使用东汉出土器物支持类型和环首基本形制，禁止照搬皇室专用铭文、错金纹样或夸张幻想结构。
- Upper-body posture：肩线明显向前旋转，手肘张开形成进攻性斜线；腰部以下不入画。
- Gaze target：直接看向画外的决策者，带有争辩压力。
- Expression：急切、自信、带挑战性。
- Silhouette cue：明显前倾、肘部展开、伸出的请战手形成斜向线，比诸葛亮更有进攻性。
- Avoid：拔刀挥砍、照搬皇室铭文与错金装饰、无来源令牌、普通持刀站姿、指地图模板、无对象怒吼、武侠飞跃。

### 马谡（如入选）

- Event moment：准备执行自己对据险部署的判断。
- Narrative function：关键执行者 / 决策偏差可能放大者。
- Competence source：参谋判断与军令执行。
- Physical verb：**定令**。
- Object interaction：一手握住经核验的简牍军令并收在胸前，另一手抬起向画外高处做明确部署手势；不画兵符或地形图。
- Prop Card：简牍军令 = `PERIOD-ATTESTED`；以汉代简牍作为文书载体的资料支持类型，只作时代化军令载体演绎，不声称是马谡本人遗物，不添加可读文字、印刷排版或地图。
- Upper-body posture：上身已经转向执行方向，肩线与抬臂形成明确动势，表现“判断已形成并将付诸行动”；不依赖前脚或跨步。
- Gaze target：画外拟部署位置。
- Expression：笃定、专注，不夸张自负。
- Silhouette cue：转身 + 抬臂 + 胸前收束手，区别于伏案决策者。
- Avoid：捧地图讲解、文士站桩、夸张轻蔑表情。

### 司马懿（如入选）

- Event moment：读完斥候急报后决定采用拖延与反制。
- Narrative function：敌方核心反制者 / 节奏控制者。
- Competence source：情报判断、资源消耗与风险控制。
- Physical verb：**研判**。
- Object interaction：一手握住经核验的简牍急报并略微收拢，另一手做低位停止/按兵手势；简牍只作 `PERIOD-ATTESTED` 文书载体演绎，不添加可读文字、地图或现代排版。
- Prop Card：简牍急报 = `PERIOD-ATTESTED`；用汉代简牍及文书用具证据支持载体类型，不声称是司马懿本人遗物。
- Upper-body posture：腰上半身克制后收、肩线平稳，动作比蜀方角色更收束，形成“先看信息再出手”的节奏。
- Gaze target：从急报抬眼看向画外远处，像在确认下一步反制时机。
- Expression：克制、冷静、警觉。
- Silhouette cue：直立后收、收拢简牍 + 低位停止手，与诸葛亮的发令和魏延的前压形成明显差异。
- Avoid：拿地图摆拍、阴险夸张笑、武将冲锋姿态、影视演员脸。

## 5. 动作特异性评分

生成前对每个人物内部评分，满分 10：

- 主题相关性 0–2：动作是否直接服务当前主题节点？
- 身份特异性 0–2：换成另一个角色后是否仍成立？若完全成立则分低。
- 道具/手势因果性 0–2：唯一人物道具是否显著增强动作或身份可读性、正在被使用/佩用且形制有依据，且没有漏画或额外道具？
- 身体可信度 0–2：重心、手部、视线是否符合动作？
- 组内区分度 0–2：剪影能否与其他角色明显区分？

低于 **8/10** 的动作不得进入图片生成。

## 6. 不要把人物“性格化”成无依据刻板印象

动作特异性必须来自可靠史实、用户设定或事件中的功能。没有依据时，用职业/任务行为而不是心理标签。例如可以说“作为前线将领，动作更偏执行与路线指示”，但不要凭空断言人物“暴躁、偏执、阴险”。
