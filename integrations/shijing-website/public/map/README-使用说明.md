# 史境开始页（2026-09-10）

使用提供的「开始页.svg」作为底图，保持原比例，铺满浏览器宽度，上下剩余空间为黑色。

- 鼠标移至蜀、魏、吴的疆域或国名：对应地图发光；点击打开势力详情。
- 12 个城楼标记支持悬停发光与点击详情；区分州、郡与城市。
- 顶部战略、事件、关系、历史编年支持悬停发光与点击详情。
- 右上角可以选择 228—234 年及季节。事件按所选时间过滤，孙吴政权中心随迁都时间变化。
- 左侧议题入口和「发起新议题」进入现有讨论页面；围绕历史事件创建议题会带入该事件的日期。
- 弹窗支持 Esc 关闭、键盘操作与焦点返回。时间和最近议题保留在当前浏览器会话中。

历史资料是已收录的参考记录，附《三国志》来源链接，并非完整历史数据库。疆域为提供的原画示意，不随日期重绘。尚未接入的实时驻军、粮草、城防不填入虚构数值。此首页不调用生图或文本 API。

## 文件

- `assets/start-page.svg`：网页内联使用的分层开始页。
- `assets/开始页原稿.svg`：提供的原稿备份。
- `assets/start/`：三国地图、城楼和原稿内嵌图像。
- `history.js`：势力、地点与带日期的历史事件。
- `app.js`：悬停、点击、日期选择与议题跳转。

通过项目启动脚本打开网页，不要直接双击 HTML；页面需要本地网页服务加载 SVG 与模块。
