# 史境 · 网页与视觉资产集成

本目录用于存放「史境」网页工程及配套素材，方便团队进行界面开发、素材维护和推演引擎对接。

## 目录结构

```text
integrations/
├── README.md
└── shijing-website/
    ├── app/                 # 网页界面与交互
    ├── agents/              # 人物、故事板及重大事件生成服务
    ├── public/              # 地图、卷轴、图标及事件图片
    ├── 人物素材库/           # 可直接复用的透明人物图
    ├── 故事板素材库/         # 可复用的故事场景图
    ├── skills/              # 生成与检查规范
    ├── scripts/             # 启动及辅助脚本
    ├── .env.example         # 环境配置模板
    ├── package.json
    ├── package-lock.json
    └── 启动史境.command      # macOS 启动入口
```

## 已有功能

- 三国地图及地区信息查看。
- 人物卡片、人物立绘和对话界面。
- 人物与故事板准备进度显示。
- 人物素材优先复用，减少重复生成。
- 50 张重大历史事件图，支持时间、地点和事件名称检索。
- 「全部事件」可滚动选择列表。
- 当前议题内的重大事件卷轴，支持展开、确认与收起。
- 确认后的重大事件收录到主页，可按议题查看。

## 本地启动

### 环境要求

- Node.js 22.13 或更新版本。
- 首次安装依赖需要联网。
- 在线人物抠图与校验流程需要 Python 3 及相应脚本依赖。

### 命令行启动

在 `shijing-website` 目录中执行：

```bash
npm ci
npm run dev:agents
```

启动后访问：

```text
http://localhost:3002
```

本机 Agent 服务默认使用端口 `4318`。

macOS 用户也可以双击 `启动史境.command` 启动。

## 配置说明

首次启动会根据 `.env.example` 创建本地 `.env`。

- 使用已有地图、人物和历史事件素材，无需重新生图。
- 在线生成需要在本地 `.env` 中填写自己的 API 配置。
- 对话推演和行动裁决需要配置并连接推演引擎。
- 本工程尚未自动连接主仓库的推演服务，需按接口约定完成对接。

请勿将真实 API 密钥、访问令牌或个人 `.env` 上传到 GitHub。

## 素材与事件说明

### 人物素材

已有的人物透明 PNG 存放于 `人物素材库`，按人物姓名匹配复用。新增人物素材应保留透明背景，并确认人物身份正确。

### 历史事件

预置的 50 张历史事件图片覆盖 219—264 年，按时间排序。它们属于历史资料库，不代表玩家当前议题中已经发生的结果。

### 议题事件

只有当前推演分支中已确认的重大结果，才应进入该议题的事件记录。玩家确认事件后，将其收录到主页的议题事件列表。

本机运行记录、生成任务数据库和个人议题存档不随源码包上传。

## 团队协作约定

1. 本工程保留独立的 `package.json` 和 `package-lock.json`，在本目录使用 npm 安装依赖。
2. 对接前请勿用本目录文件覆盖主仓库的同名配置。
3. 上传时保持目录结构完整，避免素材路径失效。
4. 不要提交 `node_modules`、`.env`、`.agent-data` 或临时日志。
5. 推演引擎接口、事件结果格式和世界状态字段需由前后端共同确认。

## 网页上传注意事项

通过 GitHub 网页上传时，需要分批上传文件。超出网页大小限制的素材须另行处理，不能默认认为已经上传成功。

上传结束后，请检查代码目录、素材目录和配置模板是否齐全，再交给队友运行。
